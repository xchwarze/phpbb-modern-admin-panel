{# Runs before the stylesheets, so the page never flashes the wrong layout or the wrong colours. It puts on : - data-studio-sidebar: "expanded" is the menu pinned open, "collapsed" the unpinned icon rail; without a stored choice, wide screens start pinned; - data-studio-choice ("system", "light" or "dark", from localStorage "dsr.ad.theme") and data-studio-theme, the colour scheme in use ("light" or "dark": in system mode, the one of prefers-color-scheme; js/studio.js follows its changes); - the class "studio-js" and the class of the sidebar colour, a known value of the board setting (studio-hue-): the accent of the content area is derived from it (css/colours.css). Per browser, never sent to the server; js/studio.js keeps it up to date. A Content-Security-Policy would need a hash of this script. g(k) reads a key and, once, moves the one the extension stored under its old name to its new name (dsr.ad.), so administrators keep their choices; js/studio.js moves the other old keys (recents, pins). #}
